# 冒險公證人 · The Loss Adjuster

保險公證人人生模擬文字遊戲。從 23 歲入行到 65 歲退休,在每個十字路口做出選擇,邊玩邊學保險理賠。

A loss adjuster life-sim set in Taiwan. From 23 to retirement at 65, make choices at every crossroads and learn real insurance along the way.

- `index.html`:語言選擇首頁 · Language picker
- `zh.html`:繁體中文版(新台幣)
- `en.html`:English version (amounts in US$, about 32 NTD per US$)

內容純屬虛構,機率為遊戲設計,非真實統計。 · Entirely fictional; probabilities are game design, not real statistics.
